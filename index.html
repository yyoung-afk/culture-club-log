Firebase 클라우드 DB 연동

Google Firebase의 내 프로젝트 firebaseConfig 설정 객체(JSON)를 아래 붙여넣으시면, 깃허브 배포 후에도 모든 친구들이 실시간으로 같은 커뮤니티 데이터를 이용할 수 있습니다.

설정하지 않아도 브라우저 LocalStorage로 기본 저장됩니다.

파이어베이스 콘솔 -> Firestore Database 규칙을 `allow read, write: if true;`로 설정하세요.
